# 本地自治模块说明

## 目标

在保留现有 `stable-layer-sdk` + `@mysten/sui` 交易主链路的前提下，引入一条独立的本地自治能力线：

- 先生成任务计划
- 再进行风险守卫检查
- 最后执行（支持 Dry Run）

该能力用于长期开源演进，不依赖比赛语境。

## 架构

### 1. Agent 侧（`packages/agent/src/local-automation.ts`）

- `LocalAutomationPlanner`：把自然语言目标转换为结构化计划（steps）
- `LocalAutomationGuard`：校验计划风险和命令白名单
- `InMemoryLocalAutomationRunner`：执行计划（当前默认模拟执行）
- `localAutomationToMarkdown`：输出可审计 Markdown 报告

### 2. Web 侧（`apps/web/src/lib/localAutomation.ts`）

- 负责调用 planner / guard / runner
- 管理本地历史记录（`localStorage`）
- 支持导出 Markdown 审计日志

### 3. UI 页面（`apps/web/src/pages/AutomationPage.tsx`）

- 路由：`#/automation`
- 输入任务目标与执行策略
- 展示守卫结果、执行结果、历史记录与导出按钮

## 使用方式

1. 打开 `#/automation`
2. 输入任务目标，例如“整理 Downloads 并输出报告”
3. 配置白名单命令前缀（如 `node,git,ffmpeg,tar,pnpm`）
4. 点击“生成计划”
5. 检查守卫结果
6. 点击“执行计划”
7. 导出 Markdown

## 安全边界

- 未在命令白名单中的 shell 步骤会被阻断
- 高风险步骤默认要求审批
- `allowNetwork=false` 时会阻断需要联网的 `git/browser` 步骤
- Dry Run 模式默认开启，避免误操作

## 后续迭代建议

2. 增加任务回滚策略

4. 与 Agent 对话动作联动（生成计划后可直接执行）
