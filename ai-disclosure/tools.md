# AI 使用披露

## 一、记录模板

每次使用 AI 工具都建议按以下格式记录：
- 工具名称
- 服务提供商
- 模型名称/版本
- 使用阶段
- 使用目的
- 日期（UTC）
- 备注（是否人工复核）

## 二、本项目已使用工具

### 1）Codex（CLI Coding Agent）
- 工具名称：Codex
- 服务商：OpenAI
- 模型版本：GPT-5 类代码模型（Codex 运行时）
- 使用阶段：架构设计、编码、调试、文档整理、代码审查
- 使用目的：提高实现效率、减少重复劳动
- 日期（UTC）：2026-02-07
- 备注：所有改动均经过人工复核

### 2）DashScope Compatible API
- 工具名称：DashScope Compatible API
- 服务商：阿里云百炼
- 模型版本：`qwen3-max`
- 使用阶段：可选的 LLM 增强实验、文案与流程草稿
- 使用目的：辅助自然语言任务
- 日期（UTC）：2026-02-07
- 备注：敏感信息均已打码，不在仓库存储真实密钥

## 三、敏感信息处理策略

- API Key 在披露文档中统一打码（如 `sk-***`）
- 钱包私钥/助记词不得写入仓库
- `.env` 文件默认被忽略，不提交到 Git
